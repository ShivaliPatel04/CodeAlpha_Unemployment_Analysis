# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment data in India using Python. The analysis focuses on unemployment trends over time, regional variations, rural and urban differences, and the impact of the COVID-19 pandemic.

The project includes data cleaning, exploratory data analysis, statistical analysis, and data visualization using Pandas, Matplotlib, and Seaborn.

## Dataset

The project uses the following datasets:

- Unemployment in India.csv
- Unemployment_Rate_upto_11_2020.csv

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

The following analysis was performed:

- Data cleaning and preprocessing
- Handling missing values
- Date conversion and time-series analysis
- Descriptive statistical analysis
- Monthly unemployment trend analysis
- Regional unemployment analysis
- Rural vs Urban unemployment analysis
- COVID-19 impact analysis
- Correlation analysis
- Identification of highest and lowest unemployment observations
- Data visualization using charts and graphs

## COVID-19 Impact

The analysis compares unemployment rates before and during the COVID-19 lockdown period.

- Average unemployment rate before COVID-19: 9.51%
- Average unemployment rate during COVID-19: 17.77%
- Increase: 8.26 percentage points

## Key Findings

- The overall average unemployment rate in the analyzed dataset was 11.79%.
- Unemployment increased significantly during the COVID-19 period.
- There were differences in average unemployment rates across regions.
- Rural and urban areas showed differences in unemployment rates.
- Monthly analysis revealed fluctuations in unemployment over time.
- Correlation analysis was used to examine relationships between unemployment, employment, and labour participation.

## Conclusion

This project provided an analysis of unemployment trends in India using Python.

The data was cleaned by handling missing values and converting dates into a suitable format for time-series analysis. Different visualizations were used to understand unemployment trends, regional differences, rural and urban patterns, and the impact of COVID-19.

The analysis showed a clear increase in unemployment during the COVID-19 period compared with the period before the lockdown.

Overall, this project helped demonstrate how data analysis and visualization can be used to identify important patterns and derive meaningful insights from real-world economic data.
